## Production notes for all 50

- **Voice:** warm, measured, confident. Never a movie-trailer read. Speed 1.0 for the 90–180s scripts, 1.1 for the 30s cuts.
- **Numbers read as words** in the VO column so the voice engine says "three thousand nine hundred and ninety-nine", not "₹3,999". Keep digits in on-screen text.
- **Every price claim** traces to `backend/src/billing/plans.ts`. Re-check before a shoot if plans have changed.
- **Feature-gated claims** are marked with the tier in the ON SCREEN column — do not show a Scale Pro screen in a Starter ad.
- **Hook rule:** if the first line does not work on its own as a scroll-stopper, the script is dead. Test hooks before producing the full video.
- **One CTA per script.** Trial for buckets 1–6 and 8–10; booked walkthrough for bucket 7.
