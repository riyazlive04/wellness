System Check

If notifications don't appear, check:

  1. Chrome: Click lock icon in address bar → Notifications → Allow
  2. Chrome Settings: Go to chrome://settings/content/notifications → make sure this site is in "Allowed"
  3. Windows: Settings → System → Notifications → turn ON for Google Chrome
  4. Windows Focus Assist: Click the notification icon (bottom right) → make sure "Focus" / "Do Not Disturb" is OFF
  5. Chrome Bell: Click the bell icon near extensions → make sure notifications are NOT paused
