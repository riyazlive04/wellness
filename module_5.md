- Multiple Food Detection
- Portion Estimation
- Cooking Style Detection
- Meal Classification
- Nutrition Intelligence
- Goal Based Analysis
- Meal History
- Analytics
- Voice Integration
- Recipe Intelligence
- Allergy Awareness
- Food Quality Analysis
- AI Learning

Primary: IFCT 2017
Secondary: USDA FoodData Central
Future: FAO Database
